# Projeto Casa — Gio & Giu

Site interativo de 3 meses de namoro.

## Arquivos
- index.html
- style.css
- script.js
- assets/

## Como abrir
Abra `index.html` no navegador.

Não precisa de servidor para funcionar. O site usa apenas HTML, CSS e JavaScript.

## Observação
A fonte é carregada do Google Fonts quando houver internet. Sem internet, o navegador usará fontes alternativas.

## Personalização
Os textos principais estão em `index.html` e `script.js`.

O contador considera:
17/03/2026 às 20:54 (horário local do dispositivo).

As quatro dicas dos presentes estão no array `hints` dentro de `script.js`.
